Principles

A few rules that keep the site from drifting into generic.

1

Let the layout do the framing.

Strong composition beats decoration. The page should feel intentional before a single hover state is noticed.

2

Keep the system reusable.

The same variables and component patterns should be able to power future pages without another rewrite.

3

Ship with restraint.

Motion, texture, and color should clarify, not compete with the message.
